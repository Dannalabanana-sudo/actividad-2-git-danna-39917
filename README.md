# Actividad 2: Configuración de herramientas Git y GitHub

**Estudiante:** Danna Vanessa Devia Mendoza  
**Actividad:** Hands on: configuración de herramientas  
**Herramientas utilizadas:** GitHub, Microsoft Word, documentos PDF y archivos de texto.

## Descripción del proyecto

Este repositorio fue creado para desarrollar la Actividad 2, cuyo objetivo es utilizar herramientas colaborativas básicas empleadas en proyectos de ciencia de datos.

El repositorio contiene un tutorial sobre Git organizado en cinco capítulos. Cada capítulo fue elaborado en un documento de Microsoft Word independiente y posteriormente exportado a formato PDF. Los documentos fueron cargados y administrados directamente desde la plataforma web de GitHub.

## Objetivos

- Crear y gestionar un repositorio en GitHub.
- Documentar un tutorial sobre Git en cinco capítulos.
- Cargar y modificar documentos dentro del repositorio remoto.
- Registrar los cambios mediante commits con mensajes descriptivos.
- Documentar el proceso realizado mediante el archivo README.md.

## Contenido de los capítulos

| Capítulo | Tema | Descripción |
|---|---|---|
| 1 | Introducción a Git | Explica qué es Git, su importancia, conceptos básicos y diferencias entre Git y GitHub. |
| 2 | Primeros pasos con Git | Describe la verificación de la instalación, configuración inicial, creación de repositorios y clonación. |
| 3 | Registro de cambios con Git | Explica el área de preparación, `git status`, `git add`, `git commit` y buenas prácticas en los mensajes de confirmación. |
| 4 | Historial y ramas en Git | Presenta `git log`, `git diff`, ramas, `git branch`, `git checkout` y `git switch`. |
| 5 | GitHub y repositorios remotos | Explica GitHub, repositorios remotos, `git remote`, `git push`, `git pull` y el flujo completo de trabajo. |

## Proceso realizado

1. Se verificó la existencia de una cuenta en GitHub.
2. Se creó un repositorio público llamado `actividad-2-git-danna`.
3. Se creó el archivo `README.md` desde la plataforma web de GitHub.
4. Se elaboraron cinco capítulos del tutorial de Git en documentos de Microsoft Word.
5. Cada documento fue exportado a formato PDF.
6. Los documentos Word y PDF fueron cargados al repositorio mediante la opción **Upload files**.
7. Se crearon archivos de texto mediante la opción **Create new file**.
8. Cada carga o modificación fue registrada mediante un commit con un mensaje descriptivo.
9. Se revisó el historial de commits para comprobar los cambios realizados.
